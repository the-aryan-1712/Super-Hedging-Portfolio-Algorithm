# Superhedging Portfolios in Markets with Transaction Costs

This repository provides a Python implementation of the mathematical framework detailed in the research paper *"An algorithm for calculating the set of superhedging portfolios in markets with transaction costs"* by Andreas Löhne and Birgit Rudloff. 

The code bridges the theoretical gap between continuous-time finance mathematics and discrete algorithmic implementation, providing tools to calculate both the scalar superhedging price and the full set of superhedging portfolios under proportional transaction costs.

---

## Theoretical Background

In frictionless markets, the cost of superreplicating an option is a single scalar value. However, when proportional transaction costs are introduced (represented by bid-ask spreads), the optimal hedging strategy depends heavily on the assets you already hold. 

This project implements two core algorithms from the paper:
* **Scalar Superhedging Price:** Calculates the absolute minimum amount of a single numéraire asset (like cash) needed to superhedge a claim, using a sequence of Linear Programs (LPs).
* **Set-Valued Superhedging:** Calculates the complete geometric set `SHP_0(X)` of all initial portfolios that can successfully superhedge the claim. This is done by formulating the problem as a sequence of Linear Vector Optimization (LVO) problems and solving them backward through the event tree.

---

## Project Structure

The architecture is divided into modular files handling specific mathematical duties:

* `market_tree.py`: Contains the `MarketNode` class. Handles the construction of the discrete-time event tree, bid-ask matrices, and the generation of positive dual solvency cones.
* `scalar_pricing.py`: Implements the Jouini-Kallal dual representation sequence. Contains the `compute_scalar_superhedging_price` function which utilizes `scipy.optimize.linprog` to find the exact scalar price bound.
* `set_valued_pricing.py`: Contains the `Polyhedron` class and the `compute_set_valued_superhedging` loop. This sets up the LVO data structures required for Theorem 4.1 of the paper.
* `benson_solver.py`: A simplified, 2D weight-sweeping solver that mimics the outer-approximation behavior of Benson's algorithm to map Pareto frontiers. 
* `main.py`: The entry point script to define assets, build the tree, and run the pricing algorithms.

## ⚙️ Dependencies

The core logic relies entirely on standard scientific Python libraries.

* `numpy`: For matrix operations and bid-ask array handling.
* `scipy`: For the `linprog` simplex/interior-point solvers used in the scalar pricing algorithm.
* `matplotlib`: For visualizing the 2D Pareto frontiers generated by the Benson-style solver.

## Important Limitations & Production Usage

This codebase serves as an **educational translation** of the mathematical proofs provided by Löhne and Rudloff. 

* **Linear Vector Optimization (LVO):** Python's `scipy` does not natively support LVO. The `benson_solver.py` provided is a simplified 2D sweep. For exact multi-dimensional vertex enumeration, you must replace the mock solver with a rigorous C++ backend. 
* **Bensolve Integration:** The authors of the paper explicitly recommend using Benson's algorithm to compute inner and outer approximations of the polyhedrons to prevent the number of vertices from growing exponentially. For production-level quantitative finance, install the official Python wrapper for Bensolve (`pip install pybensolve`) and hook it into the `set_valued_pricing.py` loop.
* **Recombining Trees:** The provided `MarketNode` class supports generic trees. For multi-period binomial or Cox-Ross-Rubinstein models, you should subclass `MarketNode` to enforce recombining paths, heavily optimizing memory usage.

## Getting Started

1. Define your initial assets and their bid-ask matrices.
2. Build a tree of `MarketNode` instances representing your time horizons.
3. Assign the terminal payoff vector to the leaf nodes.
4. Pass the root node to `compute_scalar_superhedging_price()` to get your cash-equivalent bound.
5. (Optional) Run the LVO loop to extract the full `SHP_0(X)` polyhedron geometry.
